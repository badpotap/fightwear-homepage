# Fightwear.ru — главная страница (UI-концепт)

Адаптивный статический прототип главной страницы магазина спортивной экипировки.

## Запуск
Откройте `index.html` в браузере. Для локального сервера можно выполнить:
```bash
python -m http.server 8000
```
Затем откройте `http://localhost:8000`.

## Состав
- `index.html` — разметка страницы
- `styles.css` — адаптивные стили
- `script.js` — демо-интерактивность меню, поиска и корзины
- `assets/fightwear-logo.png` — логотип из вложения

## Важно
Это фронтенд-концепт. Каталог, поиск и корзина не связаны с реальной системой заказов. Категорийные и hero-фотографии загружаются с Unsplash и требуют подключения к интернету.
Перед коммерческим использованием проверьте права на товарные знаки и изображения, а также замените демонстрационные элементы на подтверждённые данные магазина.
